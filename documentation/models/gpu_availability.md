# GpuAvailability

**Properties**

| Name               | Type  | Required | Description                             |
| :----------------- | :---- | :------- | :-------------------------------------- |
| AvailableGpuBatch  | int64 | ❌       | The number of available GPU batches     |
| AvailableGpuHigh   | int64 | ❌       | The number of available high-end GPUs   |
| AvailableGpuLow    | int64 | ❌       | The number of available low-end GPUs    |
| AvailableGpuMedium | int64 | ❌       | The number of available medium-end GPUs |
| OnCallGpu          | int64 | ❌       | The number of on-call GPUs available    |
